# DataVis_Project2
Data Visualizations Project 2 : Harry Pearson : Masters Class

This Project is my Submission for our Project 2 Assignment.
The Data is a set information from netflix.com found on Kaggle.com
To use this dashboard:
1) Run the File
2) Select the Director's or Actor's View
3) Select a Director (If you are in the directors view, you can click on the graph to gather information about the movie)
4) If you enter Actor's view, choose and actor from the drop down. (this is dependent also on what director is chosen)
5) you can see what movies this actor was in and the movie ratings for each film.
6) in either view you can search full or partial movie titles and see what data exists for those findings.
7) ENJOY!
